# سياسة العمل دون اتصال — Aghbari Commerce

## ما الذي يعمل دون اتصال؟
- يمكن فتح هيكل التطبيق والملفات العامة المخزنة مسبقاً: صفحة التطبيق، ملفات Vite ذات الأسماء الموقعة بالمحتوى، الشعار وبيان PWA.
- تعرض الواجهة تنبيهاً واضحاً عندما يبلّغ المتصفح عن انقطاع الاتصال.
- عند توفر الشبكة، تستمر كل عمليات القراءة والكتابة بالمرور عبر مساراتها الأصلية والتحقق من صلاحيات الخادم.

## ما الذي لا يُخزّن أو يُنفّذ دون اتصال؟
- لا يخزّن عامل الخدمة استجابات Supabase/API أو بيانات العملاء والطلبات والفواتير والمدفوعات والمخزون.
- لا توجد قائمة انتظار محلية للطلبات أو الدفع أو اعتماد الكميات أو حركات المخزون.
- لا يُعرض نجاح حفظ أو إرسال عندما لا يؤكد الخادم العملية.
- استعادة الاتصال لا تعيد إرسال عمليات حساسة تلقائياً؛ على المستخدم إعادة المحاولة بعد مراجعة الحالة الحقيقية.

## الحدود
حالة `navigator.onLine` إشارة من المتصفح وليست اختبار صحة لخادم التطبيق أو Supabase. قد تكون الشبكة المحلية متصلة بينما الخدمة متعطلة؛ لذلك تظل أخطاء API الفعلية هي مصدر الحقيقة. هذا التغيير يضيف app-shell PWA أساسياً ولا يدّعي إكمال العمل التشغيلي الكامل دون اتصال.
